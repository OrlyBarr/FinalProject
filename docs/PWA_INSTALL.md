# התקנת אפליקציית Israel Transit על הטלפון

האפליקציה היא **Progressive Web App (PWA)** — היא רצה בדפדפן אך מתקינה את עצמה
על מסך הבית כמו אפליקציה רגילה, עם אייקון משלה, מסך מלא ועבודה גם ללא חיבור (במצב מוגבל).

> כתובת השרת על ה-VM: `http://192.168.1.110:5000/`
> (יש לוודא שהטלפון מחובר לאותה רשת WiFi כמו ה-VM)

---

## 📱 התקנה על Android (Chrome / Edge / Samsung Internet)

1. פתחי את **Chrome** בטלפון (לא דפדפן אחר — Chrome נותן את החוויה הטובה ביותר ל-PWA).
2. נווטי לכתובת: `http://192.168.1.110:5000/`
3. תוך מספר שניות יופיע באנר תכלת בראש המסך:
   > **התקיני את האפליקציה** — גישה מהירה ממסך הבית, גם ללא חיבור
4. הקישי על **"התקיני"** → אישור → האייקון מופיע במסך הבית.

### אם הבאנר לא הופיע
- הקישי על תפריט שלוש הנקודות (⋮) בפינת Chrome.
- בחרי **"הוסף למסך הבית"** או **"התקן אפליקציה"**.
- אשרי את שם האפליקציה (ברירת מחדל: "Transit").

---

## 🍎 התקנה על iPhone / iPad (Safari)

> **חובה Safari** — Chrome ב-iOS לא תומך בהתקנת PWA, רק Safari עושה זאת.

1. פתחי את **Safari** בטלפון.
2. נווטי לכתובת: `http://192.168.1.110:5000/`
3. הקישי על כפתור השיתוף ⤴ (הריבוע עם החץ למעלה, בתחתית המסך).
4. גללי ובחרי **"הוסף למסך הבית"** (או **"Add to Home Screen"**).
5. שני את שם האפליקציה אם תרצי, ואז הקישי **"הוסף"**.
6. האייקון מופיע במסך הבית — הקישי כדי להפעיל במצב מסך-מלא.

---

## ✅ מה צפוי לראות אחרי ההתקנה

- **אייקון** עגול-תכלת במסך הבית עם איור של אוטובוס לבן ודבוקת מיקום.
- **מסך splash** קצר (תכלת, עם הלוגו) בכל הפעלה.
- **ללא שורת כתובת** של הדפדפן — כמו אפליקציה רגילה.
- **קיצורי דרך** ב-Android (לחיצה ארוכה על האייקון):
  - 🚏 *תחנות קרובות* — קופץ ישר לרשימת התחנות הקרובות שלך.
  - 🗺️ *תכנון מסלול* — קופץ ישר ללשונית תכנון המסלול.

## 🌐 שימוש בלי חיבור לאינטרנט

ברגע שהאפליקציה נטענה פעם אחת מקצה לקצה, ה-Service Worker יוצר cache מקומי
ומאפשר:

- **תמיד עובד**: פתיחת המסך הראשי, הניווט בתוך הממשק, האייקונים והפונטים.
- **עובד מ-cache**: נתוני קווים/תחנות שכבר נטענו (יוצגו עם תיוג "stale").
- **לא עובד בלי רשת**: בקשות חיות לאוטובוסים בזמן אמת ולתכנון מסלול דורשות חיבור.

אם אין חיבור והמשתמשת מנסה לפתוח דף שעדיין לא ב-cache, תוצג התראה:
> "אין חיבור לאינטרנט — נסי שוב"

## 🔄 עדכון האפליקציה

כשמעלים גרסה חדשה (push לגיט + git pull על ה-VM), האפליקציה תאתר את ה-SW
החדש ברענון הראשון, תוריד את הקבצים החדשים ברקע, ותפעיל את העדכון
**מהפעלה הבאה** של האפליקציה.

לאילוץ עדכון מיידי:
- **Android Chrome**: שלוש נקודות ⋮ → **רענן**.
- **iOS Safari**: סגרי את האפליקציה (החלקה למעלה מהשורה התחתונה במסך multitasking)
  ופתחי שוב.

## 🛠️ פתרון בעיות

| בעיה | פתרון |
|------|-------|
| הבאנר "התקיני" לא מופיע | ודאי שאת ב-Chrome (לא Edge ב-iOS), שביקרת בכתובת ב-HTTPS או ב-localhost / IP פנימי, ושלא דחית את הבאנר בעבר. למחיקה: DevTools → Application → Local Storage → מחיקת `pwa-install-dismissed`. |
| האייקון לא מתעדכן אחרי שינוי | iOS שומר את האייקון בעקשנות. הסירי את האפליקציה ממסך הבית, סגרי את Safari, התקיני מחדש. |
| "אין חיבור לאינטרנט" אבל יש WiFi | ייתכן שה-VM כבוי. בדקי `ping 192.168.1.110` מהמחשב או הפעילי את `bash run.sh` ב-SSH. |
| הדף לבן אחרי עדכון | Service Worker תקוע. ב-Chrome: DevTools → Application → Service Workers → **Unregister**. רעני. |

## 📂 קבצי PWA בפרויקט

```
finalproject-main/
├── manifest.json                 # מטא-דאטה של האפליקציה
├── service-worker.js             # cache strategy + offline fallback
├── icons/
│   ├── icon-192.png              # אייקון Android
│   ├── icon-512.png              # אייקון Android (high-res)
│   ├── icon-maskable-512.png     # אייקון adaptive (Android 8+)
│   └── apple-touch-icon.png      # אייקון iOS (180x180)
├── moovit.html                   # ה-shell עצמו (עם <link rel="manifest">)
├── bot.py                        # מגיש את כל הקבצים שלמעלה
├── docs/
│   └── PWA_INSTALL.md            # ← הקובץ הזה
└── scripts/
    └── generate_icons.py         # יצירה מחדש של האייקונים מ-PIL
```

לרענון האייקונים אחרי שינוי עיצוב:
```bash
python scripts/generate_icons.py
```
